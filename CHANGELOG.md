Floating dock designs, installed-app pins and verified in-app updates.

- Five dock designs: continuous bar, grouped floating islands, individual icon pills, separate pin/running groups and compact rail.
- Fourteen presets; asymmetric/rounded/sharp surfaces, seven icon shapes, nine static background options including local PNG/JPEG images and patterns.
- Nine hover choices plus adjustable movement, tilt, fade, scale, easing and duration. Overflow remains navigable and recovery controls stay outside scrolling.
- Windows/EMX handoff: temporary reveal hides EMX for the countdown; permanent Restore suspends EMX until resumed. Screen-edge placement uses the Windows taskbar area.
- Installed Windows app picker with real shell icons; SoundCloud's running window attaches to its installed app pin.
- Resizable EMX Audio remembers location and size, uses readable app source names, and reports unavailable timing honestly. SoundCloud media integration preserves Windows playback controls.
- Updates page checks public GitHub releases, verifies SHA-256 and package version, backs up replaced files and restarts with a startup check. Source code remains in the separate private repository; release archives contain compiled runtime files and product documentation.

Windows x64, Windows 10 version 2004 or newer. Extract the complete ZIP; launch EMX.TaskbarStudio.exe. No separate .NET installation is required.
